# 💱 Currency Converter App

A simple **Currency Converter App** built using **HTML, CSS, and JavaScript**.

This beginner project uses an **API call** to get currency exchange information and allows users to convert one currency into another.

## ✨ Features

* 💱 Currency conversion
* 🌐 API integration
* 💰 Convert different currencies
* ⚡ JavaScript-based calculations
* 🎨 Simple and clean interface
* 📱 Easy-to-use design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Currency Exchange API

## 🚀 How to Run

1. Download or clone the project.
2. Open `api.html` in a web browser.
3. Select the currencies.
4. Enter the amount.
5. View the converted currency value.
